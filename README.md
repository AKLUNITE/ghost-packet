# GHOST//PACKET

3〜5人でボイスチャットしながら遊ぶ、ブラウザ対戦のブラフゲーム。

**▶ 遊ぶ：https://aklunite.github.io/ghost-packet/**

## 遊び方

1. ホスト役が上のURLを開き、ハンドルネームを入れて「**ルームを作る**」
2. ロビーの「招待リンクをコピー」で出たリンク（またはルームコード4文字）を Discord などに貼る
3. 友達はリンクを開いて名前を入れて「参加」
4. 3人以上そろったらホストが「対戦開始」（最大5人。足りないときは練習用CPUも追加できます）

インストール・登録は不要です。1人で試すときはタイトル画面の「練習モード」へ。

## ホストの注意

- サーバーを使わず、**ホストのブラウザがゲームを進行**します（参加者どうしはWebRTCで直接つながります）
- そのため **ホストは対戦が終わるまでタブを閉じないでください**。別のタブやDiscordを見ていても進行は止まりません
- ホストはPC推奨（スマホだと画面オフ・アプリ切替で止まることがあります）
- 参加者は回線が切れても、同じ端末・同じブラウザで開き直せば同じ席に戻れます

## しくみ

- ルール：統合ゲーム設計書 v1.5 準拠（参加人数のみ 3〜5人に変更）
- 自作WebGLの3D卓、BGM・効果音はブラウザ内で生成
- 出目はホストの端末で確定し、本人以外には送られません
- 接続の仲介に PeerJS の無料ブローカーを使用（ゲームの通信内容は経由しません）

ファイル：`engine.js` ルール / `room.js` 進行 / `p2p.js` 通信 / `app.js` 画面制御 / `scene.js`・`gl.js` 3D / `audio.js` 音 / `bots.js` 練習CPU
